# Micro Utilities
This repository contains tiny utilities I made for no reason. This repo will be regularly updated.

Utilities in repository:
- Disk Wipe: disk wiping utility. Double-check drive letter before starting.
- File Reader: simple file reading utility. Read any file as text.
- SetRes: screen resolution changer in console.
- Mem Dump: memory dumpng utility.
- Run As System: elevate any app to SYSTEM level. Grants the highest level of privileges. Do not misuse.
- File Tool: multi-purpose file manipulation tool.
- Tiny Shot: minimalistic screenshot tool.
- Colorizer: changes your system colors to random.
  Includes legacy (HKCU\Control Panel\Colors), Aero (HKCU\SOFTWARE\Microsoft\Windows\DWM) and UWP/Metro accent color. Re-logon to apply completely.
- Clicker: simple clicker game. Press Space to increase counter.
- Fish: draws fish.

Feel free to modify it as you want.
