# Micro Utilities
This repository contains tiny utilities I made for no reason. This repo will be regularly updated.

Utilities in repository:
- Disk Wipe: disk wiping utility.
  WARNING: It will delete data on specified disk permanently. Double-check drive letter before starting.

- File Reader: simple file reading utility. Read any file as text.

- SetRes: screen resolution changer in console.

- Mem Dump: memory dumpng utility.

- Run As System: elevate any app to SYSTEM level.
  WARNING: Grants the highest level of privileges. Can break Windows if misused

- File Tool: multi-purpose file manipulation tool. Be careful with some commands.

- Tiny Shot: minimalistic screenshot tool.

Feel free to modify it as you want.
